# Lumen
Lumen is a minimal, notes app without distractions.
Every note is saved locally, meaning your notes are 100% private without any chance of someone else reading your notes, if you did not show it to them yourself.

# Desktop version
Lumen has 3 desktop version:

- Linux
- Windows
- MacOS

These are all identical to each other and don't have any exclusive features.
